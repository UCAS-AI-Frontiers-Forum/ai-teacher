# 案例方法规则（空模板）

- 规则 ID / 修订 / 日期 / 状态（候选、回归通过、新任务观察）：
- 获准来源案例 ID、最小证据摘记及本地路径：
- 复用/再分发许可及脱敏检查，不能附未获准原稿：
- 触发情境与适用范围：
- 原来缺少什么信息：
- 应主动采用的问题/样稿/试验，以及为什么改变决定：
- Teacher 承担的拆解、组织、选型、自检或修复动作：
- 仍需用户决定什么，何时停止：
- 正例输入、可观察结果与核对方法：
- 失败/反例及不应采用此规则的情形：
- 改入文件、版本/快照、相对旧版的具体变化：
- 来源案例与失败样例回归结果、证据：
- 全新任务评估批次及结果（未做填未验证）：
- 成本/局限、后续修订或撤回原因：

一次成功只支持本次观察，不能直接升级为普遍规则。评估样例用于修改后转为回归数据，不继续充当未见任务。
