# 单次试用记录（空模板）

复制到本地，每个条件独立记录；这不是程序可校验的数据格式。计时未知写未知，不默认零。

## 测试前冻结

- 匿名参与者/任务/配对 ID，日期、记录者：
- 探索或评估；开发/回归/预留任务归属及是否已被框架作者使用：
- 条件 A/B，执行顺序、任务分配方法及难度差异：
- 仓库提交或本地快照标识、技能/基线提示词/案例集 SHA-256：
- 模型精确名称/版本、推理档位、工具/权限、宿主基础指令、预算/时间上限：
- 原始目标、允许输入与来源/权限；可重放文件路径：
- 评估者事实表的位置、哪些事实可由提问获得：
- 事前访谈投入（单列）、是否影响用户表达：
- 通过标准/严重错误定义、确定时间：
- 有实际意义的负担改善阈值、允许的质量差异（未预设则仅描述）：
- 盲评安排、评估者及必要领域核验方式：
- 采集、保留、维护者查看及共享许可范围：

## 人工事件

| 事件 ID/起止或时长 | 人员（参与者/协助者） | 类别（澄清/安装操作/监督/纠错接管/最终验收） | 谁发起及具体原因 | 证据路径/观察或自述 |
|---|---|---|---|---|
| 待记录 | | | | |

同一人的重叠时间只计一次；多人同时投入按人时相加。观察者仅记录的研究时间另列，一旦帮助则计入协助者。必要的主动提问也计入澄清负担。

## 结果与成本

- 停止原因：完成 / 质量失败 / 预算或时间耗尽 / 主动放弃 / 其他：
- 每个质量标准的通过/失败/未知及产物证据：
- 严重错误、漏检、用户纠正和 Teacher 自行修复：
- 关键主动发现及其影响；无效/重复/诱导提问：
- 人工澄清、安装操作、监督、纠错接管、验收分钟数（参与者与协助者分列）：
- 人工总分钟数、干预事件数、维护者协助内容；缺测范围：
- 初次搭建成本与换输入复用成本分别记录：
- 是否在无维护者提示/代做下完成：
- 工具/模型成本、机器等待、总历时，纯观察记录时间：
- 用户省心程度及理由（自述，辅助信息）：
- 盲评是否实现，其他条件差异/污染：

## 配对后填写

- 两组质量结果及人工时间分项、差值、失败/缺测/放弃：
- 是否达到预先约定的门槛；是否依赖维护者、任务不等价或质量降低：
- 结论：改善 / 无明显变化 / 变差 / 无法判断；证据与适用范围：
- 结果是否用于修改框架；若是，标记转为回归集及新版本：
